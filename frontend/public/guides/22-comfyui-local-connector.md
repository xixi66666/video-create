# 本机 ComfyUI 视频连接器

工作台的 N27 提供本机 ComfyUI 视频候选生成。它与文字 Agent 的 FIXTURE/LIVE 模式独立，采用已登记的 API 格式工作流，不调用云端模型；生成后必须由操作者检查并采纳到素材库，节点不会自动标记完成，也不会自动发布。

## 启动

先准备本机 ComfyUI、GPU 环境与工作流所需的模型。本项目不随代码分发模型。下例使用本机现有的 AIMedia 安装目录；其他机器需换成自己的路径：

```powershell
.\scripts\start-comfyui-local.ps1 -ComfyHome 'D:\Code\Java_Code\AIMedia\ComfyUI'
.\scripts\start-local.ps1 -JavaHome '你的 JDK 21 目录'
```

视频实例默认监听 `127.0.0.1:8192`，使用本项目 `.run/comfyui-video/` 保存工作数据，读取外部模型目录；启动时禁用 API 节点与自定义节点，不修改原模型。可用 `-ModelDirectory`、`-PythonExecutable` 和 `-Port` 指定实际环境；如更改端口，Java 后端需同时通过 `WORKBENCH_COMFY_URL` 指定对应的本机回环地址。已占用的端口不会被脚本接管。

使用完毕可执行 `scripts/stop-comfyui-local.ps1`；脚本只停止身份匹配的本项目实例，队列非空时拒绝停止。停止工作台仍使用 `scripts/stop-local.ps1`。两者分别管理，不会自动停止其他 ComfyUI 进程。

## 使用与范围

1. 在作品中完成 N24、N25/N26 的适用项和 G03 制作方案确认。
2. 打开 N27「本机视频生成」，检查连接与模板就绪情况，填写符合已确认分镜的描述和随机种子，然后生成候选视频。系统核对依赖和版本，不自动判断提示词与分镜的语义是否一致。
3. 页面轮询任务状态。候选完成后查看视频，选择「采纳到素材库」；采纳前重新检查依赖、G03 和输入快照。采纳不会修改节点产物，也不会将节点标记完成。

示例模板为 `backend/config/comfy-templates.json` 中的 `local-h3-video-v1`，工作流在 `backend/config/workflows/h3-local-api.json`。它固定使用本地 MiniMax H3 所需权重、竖屏 384×640、24fps、124 帧、12 步；允许填写提示词与种子。模板和绑定属于配置，不是节点目录中的硬编码。实际安装的 ComfyUI、节点和权重须通过就绪检查；登记模板不等于已验证所有环境。H3 模型受其独立的 [MiniMax H3 Community License](https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/LICENSE) 约束，发布或对外提供服务前应核实适用条件。

另有 `local-h3-landscape-v1` 横屏模板，使用 768×448、24fps、124 帧和 12 步；如需精确 16:9，后期需从画面顶部和底部各裁去 8 像素，得到 768×432。该模板与竖屏模板均只绑定提示词和种子，不支持向连接器传入参考图，也不保证多镜头人物一致性。节点和模型就绪检查通过不代表横屏画面效果已经验收。

## 任务恢复与限制

任务和工作流快照持久化在业务库中。提交前再次检查输入与拍板；提交超时或重启后受理情况不明时，记录为 `UNKNOWN`，只用原任务 ID 查询队列与历史，不自动再次提交。恢复候选文件回收时使用同一文件标识，防止重复导入。连接器不提供取消、全局清队列或中断其他任务的功能；任务可能长时间处于未知状态，需先恢复原 ComfyUI 实例和历史记录再对账。

页面也会保留提交结果未知的编号，即使刷新也不会自动重复提交；若后端记录始终没有出现，需先根据该编号排查，当前界面不提供强制清除未知提交的操作。

当前只接入本机回环地址和 N27 MP4 视频候选，素材上限为 50 MB。服务不可达、缺节点或模型、执行失败，以及输出过大时会显示状态，不会冒充生成成功。没有实现远端机器连接、多镜头批量调度、OBS、FFmpeg、TTS 或发布平台连接器；模型与生成内容仍需人工检查。

`/api/v1/health` 中的 `externalExecutionEnabled=false` 沿用原有“自动推进不自动执行外部工具”的含义；本机连接器的实时就绪状态通过 `/api/v1/comfy-runs/readiness` 查询。

## 本机验收记录

2026-10-30 在隔离 H2 数据库和独立素材目录中，使用本机 RX 9070 XT、ComfyUI 0.37.4 和已登记的 H3 模板完成一次真实视频联调：工作台提交、持久任务跟踪、回收、SHA-256 校验和显式采纳均通过；重复采纳只创建一份素材，N27 未被自动完成。结果为 H.264 384×640、24fps、124 帧，视频与音轨均能解码；未对音轨做主观听审。测试没有向现有工作区写入验收作品，没有调用云端模型或发布。

Java 测试共 18 项通过，覆盖并发提交、断线未知、恢复、过期输入与采纳；前端 12 项领域测试、生产构建及 3 项连接器浏览器测试通过。真实多机、多副本并发部署、超过 50 MB 输出和不同 ComfyUI 版本尚未验收。
