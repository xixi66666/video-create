**状态图例**:🟢 active 可发布 · 🟡 draft 结构未齐,不得发布 · ⚪ retired 已退役,仅供复现

## 怎么选

1. 按**戏路**筛(侠女 / 少年 / 老者 / 反派 / 旁白)
2. 按**音色标签**匹配角色设定
3. 用 `calm` 预设试听一句,再听 `intense` 判断爆发力够不够
4. 只选 🟢 active 的进发布项目

## 缺什么角色

按 SPEC 附录 A 建目录 → 填声卡 → 录 3 条参考干声 → 补预设 → 登记。
参考音频质量占克隆效果九成,不要用带混响的素材凑数。
