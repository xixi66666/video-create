# 参考音频录制要求

这个目录放参考干声。**零样本克隆里,音色质量的九成由这里决定**,不是模型。

## 硬性要求

| 项 | 要求 |
|---|---|
| 格式 | WAV 或 FLAC,**禁止 MP3** |
| 采样率 | ≥44100 Hz |
| 位深 | 24 bit |
| 时长 | **10–14 秒**,硬上限 **15 秒** |
| 声道 | 单声道 |
| 内容 | 该角色**情绪最典型**的一句台词 |
| 电平 | -23 LUFS 左右,峰值 ≤ -3 dBFS |

### 为什么是 10–14 秒

| 事实 | 后果 |
|---|---|
| IndexTTS-2.5 只取参考音频的**前 15 秒**,超出的部分**静默丢弃,无日志告警** | 给 30 秒素材 = 后 15 秒白录,而且你不知道 |
| 说话人相似度在参考音频 **~10 秒后趋于饱和** | 10 秒是性价比拐点,不是越多越好 |
| **参考音频的语速和语调会被一并克隆** | 样本定表演基线;情感预设只能在这个基线上微调,不能反向纠正 |

> 最后一条最容易被忽略:如果参考音频是"新闻播报腔",后面加再多情绪向量也救不回来。
> **录参考音频时就要用目标角色的说话方式**,而不是念一段标准普通话。

## 严禁

- ❌ 带 BGM 或环境声
- ❌ 带混响 / 房间感(克隆会把混响当成音色的一部分)
- ❌ 多段拼接
- ❌ 齿音刺耳 / 有爆音 / 有底噪
- ❌ 从成片里截取(已被压缩和处理过)

## 三条都录

| 文件 | 用途 |
|---|---|
| `calm.wav` | 主参考。决定基础音色,必录 |
| `intense.wav` | 激烈戏。也用作 `emotion=` 的情绪参考 |
| `whisper.wav` | 低语/气声戏 |

## 录完自检

1. 单独播放,能否听出房间感?能 → 重录
2. 波形是否贴顶?是 → 降增益重录
3. 用 `ffprobe` 确认采样率/声道数
