# 接入 TTS API(试听 / 克隆)

> 目标:拿到一个 key,填进环境变量,操作台里就能"用这个角色念一句"。
> 配置在 [`_shared/tts_api.yaml`](../_shared/tts_api.yaml),**密钥永不入库**(SPEC L3-07)。

## 已经支持的协议

| 供应商 | 协议 | 能否克隆 | 状态 |
|---|---|---|---|
| 任意 OpenAI 兼容端点 | `POST /v1/audio/speech` | ❌ 只有预置音色 | ✅ 已实测 |
| Fish Audio | `POST /v1/tts` | ✅ 零样本克隆 | 按文档实现,未实测 |
| MiniMax / 豆包 | 需要 appid+token | ✅ | 留位,未实现 |

## 配置方法

```powershell
# OpenAI 兼容(聚合站 / 自建代理 / Azure 兼容层)
$env:TTS_BASE_URL = "https://你的端点"
$env:TTS_API_KEY  = "sk-..."

# 或者 Fish Audio
$env:FISH_API_KEY      = "你的 key"
$env:FISH_REFERENCE_ID = "平台上建好的音色 id"   # 可留空,用角色自带的 refs/calm.wav
```

改完**重启操作台**才生效(双击 `start.cmd`)。

> 想持久化用 `setx TTS_API_KEY "sk-..."`,但要重开终端。

## 在界面上怎么用

角色库 → 选中角色 → 拉到底「试听(克隆)」→ 选供应商和预设 → 填台词 → 合成试听。

合成结果会显示:供应商、时长、采样率、文件大小,并直接播放。

## 会自动做的三件事

| 动作 | 规则 |
|---|---|
| 数字转汉字(「第3集」→「第三集」) | L1-03,替代装不上的 pynini |
| 库内 `rate`(>1 更快)翻译成供应商语义 | L3-02 |
| 超 200 字拒绝,不静默截断 | L1-02 / L5-04 |

## 免费额度能不能撑住

| 用途 | 大概够不够 |
|---|---|
| 验证"这套流程能不能用" | 够 |
| 试几个音色、调情绪 | 够 |
| 做一集 15 秒片 | 勉强 |
| 日更 | 不够 |

**免费额度的意义是验证,不是生产。** 真要做量,要么付费,要么有自己的 GPU。

## 已知限制

| 限制 | 说明 |
|---|---|
| 只支持单句 | 长文本要先在脚本层切 beat(L1-02) |
| 不做混音 | 合成出来是干声;混音链在 `postprocess.yaml`,尚未实现 |
| 不写 take_log | 现在是手动试听,没有自动 3-take |
| Fish 未实测 | 字段若变动,改 `console/synth.py` 的 `_fish()` |

## 换供应商要改哪里

只改 `_shared/tts_api.yaml` 里对应 provider 的 `model` / `voice` / `base_url`,`synth.py` 不用动。

## 故障排查

| 报错 | 原因 |
|---|---|
| `缺少环境变量 TTS_API_KEY` | 没设,或设完没重启服务 |
| `HTTP 404` | 端点不支持 `/audio/speech`(很多聚合站只做 chat) |
| `HTTP 401/403` | key 无效或余额不足 |
| `接口返回 JSON 但没有音频字段` | 该端点格式不同,需在 `_save_audio` 里加字段名 |
| 合成成功但听不到 | 浏览器拦截自动播放,点一下播放器 |
