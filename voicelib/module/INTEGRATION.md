# 配音模块 × 视频流水线:集成点

> 本文定义**模块插在哪里、前后各是谁**。契约见 [CONTRACT.md](CONTRACT.md)。

## 1. 阶段位置

```
① 剧本/拆beat → ② 分镜 → ③ 画面生成 → ④ 视频片段
                                          │
                                          ▼
                                    ┌───────────┐
                                    │ ⑤ 配音阶段 │  ← 本模块
                                    └───────────┘
                                          │
                                          ▼
                                  ⑥ 字幕轴 → ⑦ 混流渲染 → ⑧ 交付
```

**模块不是"最后一步"**,它夹在画面和渲染之间,因为:

- 下游镜头时长由**音频实测时长**决定(L5-01)
- 下游字幕轴由**音频采样帧**决定(L5-02)

顺序反了,声画必然错位。

---

## 2. 进入条件(模块可拒绝启动)

| 条件 | 检查方式 | 不满足时 |
|---|---|---|
| 脚本 beats 已定稿并通过 schema | L1-01 / L1-05 | `E1001` |
| 角色已登记、授权有效 | 铁律 3 / 4 | `E2001` / `E2002` |
| 参考音频就位且指纹匹配 | L2-06 / L2-09 | `E2003` / `E2004` |
| **`stage=final` 时画面必须已冻结** | L5-08 | `E5006` |

> 最后一条最容易漏:草声跑完就直接升终声,结果后面又改了两句台词,整集重录。

---

## 3. 退出条件(交给下游的东西)

模块返回 `pass` 时,调用方**只能**消费以下字段:

| 字段 | 下游用途 | 对应规则 |
|---|---|---|
| `manifest.beats[].duration_s` | 镜头时长 = Σ 所属 beat 时长 | L5-01 |
| `manifest.beats[].text_spans` | 字幕 cue 的起止 | L5-02 / L3-04 |
| `manifest.master.audio` | 混流输入 | — |
| `manifest.master.lufs` | 与 BGM 配比 | L0-01 |

**禁止**调用方自己估时长、自己按字数分摊字幕。这两个是声画错位的全部来源。

---

## 4. 调用时序

```
调用方                         配音模块
  │                               │
  ├─ 1. 提交 VoiceRequest ───────▶│
  │                               ├─ 入口校验(1xxxx)
  │                               ├─ 资产/授权校验(2xxxx)
  │                               ├─ 合成(3xxxx)
  │                               ├─ 混音(4xxxx)
  │                               └─ 交接校验(5xxxx)
  │◀──── 2. VoiceResult ─────────┤
  │      {verdict, manifest, qc}  │
  │                               │
  ├─ 3. verdict == pass ?         │
  │      是 → 用实测时长排镜头     │
  │      否 → 停止,展示 qc 失败项 │
```

**禁止的接法**:

| ❌ 反模式 | 为什么不行 |
|---|---|
| 先渲染画面,再补配音 | 时长对不上,只能硬拉或空转 |
| 拿到音频就自己算时长 | 与实测差 100–300 ms,累积到整集就是错位 |
| `verdict=reject` 仍继续渲染 | 把门禁变成装饰,规范立即失效 |
| 在项目里覆写混音参数 | 跨项目听感不一致(L4-01) |

## 5. 与其他模块的交接物

| 上游 → 本模块 | 本模块 → 下游 |
|---|---|
| `S01.beats.yaml`(编剧产出) | `voice/manifest.json` |
| 项目 `voice.yaml`(角色选择) | `voice/master.wav`(48k/24bit) |
| 授权文件(法务) | `voice/qc-report.json` |
| — | `voice/subtitles.srt`(由 text_spans 生成) |

---

## 6. 失败时的降级边界

| 失败点 | 允许降级 | 禁止降级 |
|---|---|---|
| 某供应商不可用 | 切 `fallback_order` 下一位 | 用静音/空白顶上 |
| 无 `text_spans` | 判 `conditional`,走强制对齐补字幕 | 按字数分摊 |
| 参考音频未就绪 | 停留 `draft` 出内部预览 | 拿去发布 |
| 最终质检不过 | 退回重做指定块 | 改阈值让它过 |

> 最后一行值得强调:**让规则通过的正确方式是改音频,不是改阈值。** 阈值只能在有实测数据支撑时整体调整(如首轮终声后校准语速)。
